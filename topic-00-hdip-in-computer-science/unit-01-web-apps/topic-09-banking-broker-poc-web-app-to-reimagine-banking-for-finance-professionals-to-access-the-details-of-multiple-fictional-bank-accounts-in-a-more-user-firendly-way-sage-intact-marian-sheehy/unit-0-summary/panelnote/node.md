### Abstract

Bank Broker is a proof-of-concept web Application for bank reporting capabilities. Current banking applications are dated in their user friendliness. They are limited in their reporting selection and tend to have very restricted access to historic data. This application will be a user hub with links to the main Irish banks. Users can access all the data in one place, perform data analysis and create more meaningful financial reporting. Data will be retrieved using Plaid software, which uses official bank APIs and OAuth, allowing connection through the bank’s portal, using a secure access token
