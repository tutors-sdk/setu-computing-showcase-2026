## Compound – A Full-Stack Gym Workout Tracker - Eoin Geoghegan


### Abstract

Compound is a full-stack web application built with JavaScript, Svelte, Node.js, and Hapi. Users can create custom workouts, view predefined templates, and track completed custom sessions with timestamps. Workouts and exercises can be added, edited, or deleted. The app includes session-based authentication, an admin dashboard, and stores data using MongoDB with Mongoose and lowdb. It demonstrates full-stack development, CRUD operations, RESTful API integration, and user-focused functionality for managing and tracking workouts.
