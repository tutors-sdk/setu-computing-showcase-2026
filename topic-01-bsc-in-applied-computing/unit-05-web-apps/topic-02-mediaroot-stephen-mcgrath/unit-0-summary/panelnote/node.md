### Abstract

This project provides both frontend and backend applications as a home media centre solution. While various solutions already exist, some have unwanted monetisation, while others include complex features and present a confusing UI, which can be difficult for people less experienced with technology to understand and manage. This program strikes a balance between these: no core functionality requires payment, yet it is easy to set up and navigate the features of the application. It supports various types of media, which are stored in the server's database and accessible from the web client.
