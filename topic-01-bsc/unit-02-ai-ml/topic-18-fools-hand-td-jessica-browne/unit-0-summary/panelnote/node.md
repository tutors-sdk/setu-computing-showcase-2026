## Fools Hand TD - Jessica Browne


### Abstract

**Fools Hand TD** is a Roguelite tower defence game. The aim is to defend against waves of approaching enemies with randomised towers each run. The player is given a choice of towers at intervals throughout the run using the towers to defeat enemies to gain money to repeat the cycle.  Half way trough the defence the player will have to move to a new map with their currently unlocked towers, forcing them to adapt to a different path and different enemy types. If the player fails to defeat too many enemies they lose. Once a run is complete permanent upgrades can be unlocked trough the main menu.
