### Abstract

Neon Sprint is a retro-inspired arcade racing game being developed as a final year project for desktop PC using Unity and C#. The project focuses on creating a fast, accessible, and replayable racing experience built around responsive controls, drifting, boost mechanics, and competitive AI opponents. Players race across stylised tracks in short, high-intensity events that reward both speed and driving skill. The project combines gameplay design, 3D asset creation, interface design, and iterative development using an Agile approach.
