### Abstract

This project investigates how user experience (UX) design influences cybersecurity behaviour, with a focus on password security. Users often ignore warnings, reuse weak passwords, and prioritise convenience due to security fatigue and poorly designed interfaces.

A system compares a baseline interface with a UX-optimised version that provides clear feedback and real-time time-to-crack indicators. The aim is to evaluate whether improved design can influence user decision-making, increase engagement with security features, and encourage the creation of stronger, more secure passwords.
