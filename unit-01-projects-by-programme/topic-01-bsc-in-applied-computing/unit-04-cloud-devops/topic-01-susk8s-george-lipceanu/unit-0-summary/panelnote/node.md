### Abstract

Kubernetes natively lacks mechanisms to manage the carbon impact of growing cloud workloads. SUSk8s addresses this by turning energy into a configurable signal which can be installed in Kubernetes clusters. It uses Custom Resource Definitions for declarative policy enforcement and a custom operator to manage these, with Kepler, Prometheus and Grafana providing supporting telemetry.  A custom scheduler runs alongside the default, prioritising low-carbon nodes via a custom scoring plugin, with the custom operator running a rescheduler controller continuously evicts non-compliant pods.
